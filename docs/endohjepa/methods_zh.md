# Endo-HJEPA 方法中文说明（归档索引）

正式投稿正文以 `endohjepa.tex` 为唯一真源；数值以
`verified_metrics.json` 为唯一真源。本文件不包含可引用实验数字。

- 主任务：跨腹腔镜、GI 和支气管镜的离线潜表示预测。
- 动作分支：使用连续、相机坐标系 SE(3) 增量进行条件预测关联和
  offline replay；不构成真实因果干预、临床安全或机器人执行结论。
- C3VD：外部动作评估仅使用 `DATA_ACCESS.md` 所列的固定十轨迹 manifest
  （798 个窗口）；不得声称评估了其他未登记资产。
- ION：私有数据。伦理声明已按医院数据治理模板定稿（回顾性、完全去标识化
  的二次分析，无受试者招募/干预/可识别信息），见主稿 Declarations；
  独立复现 ION 相关数值需获得该私有队列的授权访问。
